# schweminOPT best job shop schedules

The best schedule per job shop instance found by the schweminOPT GPU solvers, published at
**https://marci172.github.io/schweminOPT-schedules/** (table, interactive Gantt charts, downloads).

- Every schedule is checked against [ScheduleOpt](https://github.com/ScheduleOpt/benchmarks)'s own instance file:
  job order, machine capacity, every operation exactly once, and the makespan recomputed from the machine sequences
  (semi-active schedule). Below ScheduleOpt's lower bound would be reported as an error.
- `solutions/<instance>.json` is ScheduleOpt's solution format: `{"instance", "makespan", "solution"}`, where
  `solution[m]` lists machine m's operation ids in processing order (id = job-major index of the operation).
- `data/` holds the table (`index.json`) and the Gantt data per instance (up to 20,000 operations).

Generated by `scripts/make_site.py` of the (private) solver repository. Best known values: ScheduleOpt benchmarks,
